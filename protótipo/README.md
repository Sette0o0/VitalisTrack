# VitalisTrack — protótipo navegável

Rascunho de interface para Android baseado no backlog e nos requisitos do projeto. O protótipo foi construído em HTML, CSS e JavaScript sem dependências e serve como referência visual e de navegação para a implementação futura em React Native.

## Como abrir

Abra `dist/index.html` diretamente no navegador. Não é necessário instalar dependências ou executar um servidor.

## Fluxos representados

- login, cadastro e biometria;
- resumo diário com passos, água e calorias;
- registro rápido e histórico de hidratação;
- diário alimentar e cadastro de refeição;
- seleção, início e acompanhamento de atividade física;
- painel de progresso e tendências;
- central de saúde e bem-estar;
- linha do tempo de registros;
- perfil, preferências, sincronização e exportação.

## Direção de interface

O protótipo segue padrões do Material Design 3 para Android: barras superiores, navegação inferior, FAB, bottom sheet, diálogos, chips, campos outlined, botões com estados, snackbar, hierarquia de superfícies e alvos de toque adequados. A densidade e o conteúdo foram mantidos no nível de wireframe de alta clareza, não de interface final.

## Mapeamento para React Native

As telas foram organizadas para facilitar a futura tradução para componentes de navegação e UI em React Native. Os dados são ilustrativos e as interações ficam restritas ao navegador; nenhuma persistência ou integração com backend foi implementada.
